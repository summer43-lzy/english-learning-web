# LinguaLift 英语学习平台

LinguaLift 是一个面向英语初级和中级学习者的静态学习网站原型，覆盖日常英语、商务英语、雅思词汇背诵、每日总结和英文行业资讯入口。

## 功能

- 账号登录与登出：使用浏览器本地存储模拟账号状态。
- 雅思词汇：查看单词、释义、音标、例句，标记已学并统计未学词汇。
- 日常对话：覆盖咖啡店点单、问路交通、看医生、租房沟通等生活场景，并支持浏览器语音朗读跟读。
- 商务英语：覆盖会议开场、邮件跟进、客户需求确认、谈判让步等商务场景，并支持语音朗读跟读。
- 每日总结：保存当天学习复盘，结合词汇和发音练习形成学习概览。
- 英文资讯阅读：提供 GamesIndustry.biz News、TechCrunch Startups、TechCrunch Apps 和 SCMP Tech 的阅读入口与任务模板。

## 本地运行

```bash
npm start
```

打开 <http://localhost:4173> 查看网站。

## 检查

```bash
npm run check
```
